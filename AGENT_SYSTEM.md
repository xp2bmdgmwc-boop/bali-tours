# Agent Systems Architecture: Bali Tours (UHNW)

## 1. Архитектура Агентов (Роли)

Для предотвращения хаоса и микроменеджмента, мы вводим 3 специализированные роли:

1. **InDesign_Engineer**
   - **Цель:** Безопасное изменение `.indd` файлов.
   - **Инструменты:** Headless ExtendScript (`.jsx`).
   - **Ограничения:** Никаких перерисовок UI (`enableRedraw = false`), один скрипт = одна транзакция (`UndoModes.FAST_ENTIRE_SCRIPT`).

2. **Web_Engineer**
   - **Цель:** Разработка Next.js/HTML лендингов.
   - **Инструменты:** Редактирование кода, локальный сервер (только по команде).
   - **Ограничения:** Строгое соблюдение веса проекта (до 100 МБ) и структуры Vercel.

3. **Visual_QA_Director (Ключевой контроллер)**
   - **Цель:** Абсолютный контроль UHNW эстетики (стандарты Cresco, Zero Friction).
   - **Инструменты:** `mcp_playwright` (для web-скриншотов), DOM-экстракция (для InDesign).
   - **Ограничения:** Не пишет рабочий код. Только инспектирует и дает точные числовые указания инженерам. Категорический запрет на экспорт InDesign в растр для проверки.

## 2. Рабочий процесс (Visual QA Loop)

1. **Итерация 1 (Draft):** Инженер вносит изменения (запускает JSX или правит CSS).
2. **Инспекция (Extract):** Visual QA запрашивает DOM-данные (`geometricBounds`, `appliedFont`, `fillColor`) или делает скриншот веб-страницы.
3. **Корректировка (Fix):** Visual QA возвращает Инженеру точные координаты (например, "сдвинь фрейм на 15pt вниз", "замени PT Serif на Tenor Sans").
4. **Завершение (Quality Gate):** Максимум 3 попытки (согласно Two-Attempt Rule из глобальных правил). Если на 3-й раз не идеально — процесс замораживается, выдается диагностика для Валерия.

## 3. Definition of Done (DoD)
- Отсутствие переполнения текста (overset = 0) и нахлеста фреймов в InDesign.
- Типографика строго соответствует UHNW-реестру (Tenor Sans, Manrope, Cormorant Garamond, Inter).
- Цветовая палитра соответствует утвержденной (Paper White, Obsidian, Terracotta).
- Никаких заглушек (`// TODO`). Код написан полностью.
- Web: 0 ошибок в консоли. InDesign: скрипт выполнен без try/catch "тихих" падений.
